# 系统资源监控脚本

一个跨平台的 Shell 系统资源监控脚本，支持 Ubuntu 24.04 和 macOS。

## 功能特性

- ✅ 跨平台支持：Ubuntu 24.04、macOS
- ✅ 监控项：CPU、内存、网络带宽、磁盘IO
- ✅ CPU、内存显示总量百分比
- ✅ 网络带宽：每个网卡单独显示一栏
- ✅ 定时刷新不滚动，直接覆盖数据
- ✅ 彩色显示：根据使用率自动变色
- ✅ 刷新间隔可通过命令行参数配置

## 颜色说明

| 使用率范围 | 颜色 |
|-----------|------|
| < 30%     | 白色 |
| 30-80%    | 黄色 |
| 80-95%    | 黑色 |
| 95-100%   | 红色（背景高亮） |

## 文件说明

- `install.shell` - 依赖工具安装脚本
- `main.shell` - 主监控脚本

## 使用方法

### 1. 安装依赖

```bash
bash install.shell
```

### 2. 运行监控

```bash
# 使用默认刷新间隔（2秒）
bash main.shell

# 指定刷新间隔（例如5秒）
bash main.shell 5
```

### 3. 退出监控

按 `Ctrl+C` 退出

## 监控内容

1. **系统整体使用率**
   - CPU 使用率
   - 内存使用率
   - 磁盘 I/O 使用率

2. **各网卡网络带宽监控**
   - 网卡名称
   - 下载速率（KB/s 或 MB/s）
   - 上传速率（KB/s 或 MB/s）

## 注意事项

- 首次运行网络数据需要计算，请等待一个刷新周期
- 需要安装 bc、sysstat、ifstat、net-tools 等工具
- 建议在支持 ANSI 颜色的终端中运行

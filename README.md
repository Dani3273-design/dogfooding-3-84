# 系统资源监控脚本

一个跨平台的 Shell 脚本，用于实时监控系统资源使用情况，支持 Ubuntu 24.04 和 macOS。

## 功能特性

- **CPU 监控**: 实时显示 CPU 使用率百分比
- **内存监控**: 实时显示内存使用率百分比
- **网络带宽监控**: 每个网卡单独显示接收和发送速率
- **磁盘 IO 监控**: 显示磁盘 IO 使用率
- **颜色预警**:
  - 🟢 白色: < 30% (正常)
  - 🟡 黄色: 30% - 80% (注意)
  - ⚫ 黑色(黄底): 80% - 95% (警告)
  - 🔴 红色: 95% - 100% (危险)
- **无滚动刷新**: 数据直接覆盖，屏幕不会滚动
- **可配置刷新间隔**: 通过命令行参数设置

## 安装依赖

在运行监控脚本之前，需要先安装依赖：

```bash
chmod +x install.sh
./install.sh
```

### 安装的依赖

- **bc**: 用于浮点数计算
- **top**: 用于获取 CPU 使用率
- **free** (Linux): 用于获取内存信息
- **vm_stat** (macOS): 用于获取内存信息
- **iostat**: 用于获取磁盘 IO 信息
- **ip** (Linux): 用于获取网卡信息
- **netstat** (macOS): 用于获取网卡信息

## 使用方法

### 基本使用

```bash
chmod +x main.sh
./main.sh
```

### 设置刷新间隔

```bash
# 设置刷新间隔为 5 秒（默认 2 秒）
./main.sh 5

# 设置刷新间隔为 1 秒
./main.sh 1
```

### 退出监控

按 `Ctrl+C` 即可退出监控脚本。

## 注意事项

1. **首次运行网络监控**: 第一次显示网络数据时会显示"计算中..."，因为需要获取两次数据来计算速率
2. **权限问题**: 某些系统信息可能需要管理员权限，如果遇到问题请尝试使用 `sudo`
3. **macOS iostat**: macOS 上的 iostat 输出格式与 Linux 不同，磁盘 IO 显示可能略有差异

## 故障排除

### 缺少依赖

如果运行 `main.sh` 时提示缺少依赖，请运行：

```bash
./install.sh
```

### bc 命令未找到

macOS 用户如果没有安装 bc，可以通过 Homebrew 安装：

```bash
brew install bc
```

Ubuntu/Debian 用户：

```bash
sudo apt-get install bc
```

### 网卡显示不完整

脚本会自动过滤掉虚拟网卡（如 docker、veth 等），只显示物理网卡。
